      Help & tips
      How it works
      1. Choose a type on the left: Images, Videos or GIFs.
      2. Add files. Drag them in, or click Browse… to pick them in Finder. A whole folder works too.
      3. Pick a preset and press Start.
      Which preset should I use?
      • Images for a website: WebP.
      • Images for social posts: Social.
      • Just make it smaller: Compress keeps the same format and size.
      • Videos: Compress is a safe default. Social is 1080px wide.
      • GIFs for Slack or docs: Medium, or Slack for the smallest file.
      Where do my new files go?

      Into a new folder called Outputs … right next to your originals, e.g. Outputs img-webp. Your originals are never changed. Running the same preset again replaces the files in that folder.

      Why does a file say “kept original”?

      Some files are already as small as they can get, for example a JPEG that was heavily compressed before. Compressing it again would make it bigger.

      When that happens, the app copies your original into the Outputs folder unchanged, with -original added to the name (e.g. beach-original.jpg), so nothing ever gets bigger. The summary after each run lists these files.

      Presets that convert or resize (WebP, Social, Half size…) always keep the new file, because the original isn't in the format or size you asked for. If one of those comes out bigger, it's marked larger.

      Can I check a file before compressing?

      Yes. Double-click any file in the Files list to preview it full size; videos play. Use the ← → arrow keys (or the arrows on screen) to move through the list, and Esc, the ✕ or a click outside to close.

      Where can I see past runs?

      Click History in the sidebar. Every run is saved there with its before and after sizes, any kept originals or failures, and a button to open its Outputs folder. History is kept on this Mac only.

      Notifications

      If you switch to another app while a batch runs, Compress Studio notifies you when it finishes, if a file fails, or if macOS blocks a folder. The first time, macOS asks whether to allow notifications. Click Allow.

      To change this later: System Settings → Notifications → Compress Studio.

      macOS says it can't open a folder

      The first time you use a folder like Desktop, Documents or Downloads, macOS asks whether Compress Studio may access it. Click Allow.

      If you clicked “Don't Allow” by mistake, turn it back on in System Settings → Privacy & Security → Files & Folders → Compress Studio.

      Videos are taking a long time

      Videos are hard work, especially long or 4K ones. Leave the app open; your Mac won't go to sleep while it's working, and you'll get a notification when it's done. Presets marked Slower take 3–4× longer for a slightly smaller file.

      A file failed

      The file may be damaged, still downloading, or a format we can't read. Try opening it in QuickTime or Preview first. Other files in the batch carry on as normal.
